# Running W3_Gihun_Lee.ipynb

This notebook uses the following Python packages:

- `pandas`
- `numpy`
- `matplotlib`

## Run in Google Colab

These packages are preinstalled in Google Colab, so no additional installation is normally required.

1. Open [Google Colab](https://colab.research.google.com/).
2. Select **File > Upload notebook** and upload `W3_Gihun_Lee.ipynb`.
3. Select **Runtime > Run all**.

Only if you encounter a package import error, run the following cell first:

```python
%pip install pandas numpy matplotlib
```

## Run locally

Run the following commands in an environment with Python 3:

```bash
python3 -m pip install jupyter pandas numpy matplotlib
python3 -m jupyter notebook W3_Gihun_Lee.ipynb
```
