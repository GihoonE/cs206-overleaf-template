# AI Subscription Comparison Prototype

An interactive COMSCI/ECON 206 research prototype for comparing AI subscription plans across three information stages.  
Stage 3 presents four benchmark-normalized quality views — **Overall, Reasoning, Coding, and Agentic** — from the accompanying computational notebook. These scores are the current benchmark-quality component of the proposed SUU framework, not final capacity-adjusted SUU values.
